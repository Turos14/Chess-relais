# Chess-relais

## GitHub Pages

Le workflow GitHub Actions publie `index.html` sur GitHub Pages à chaque push
sur `main` et peut également être lancé manuellement depuis l'onglet Actions.
Dans les paramètres du dépôt, configurez **Pages > Build and deployment >
Source** sur **GitHub Actions**.

Cette page est un lien vers l'administration hébergée sur Vercel. Le code de
l'application n'étant pas présent dans ce dépôt, le workflow ne déploie pas
l'application elle-même.
